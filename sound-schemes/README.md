# Sound schemes

Source for Wixen Mail's importable sound-scheme packs. Each subdirectory is
one scheme: a `scheme.toml` manifest and the sound files it names, in the
same shape the application reads back after a zip import. See
[`docs/plans/20260823-earcon-sound-schemes.md`](../docs/plans/20260823-earcon-sound-schemes.md)
for the full design.

To try a scheme without waiting for it to be hosted anywhere: zip one of
these subdirectories (the `scheme.toml` and the `sounds/` folder, not this
README) and import it through Settings, Feedback, once importing is built.

See [`CREDITS.md`](CREDITS.md) for where each scheme's sounds came from and
under what license.
