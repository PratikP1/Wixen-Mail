<objective>
Give a contact the move that the other four kinds have, and answer the question
that made it impossible: which group is it leaving.

Purpose: criterion 2 of phase 5, and PIM-02's first `[D]` line, which decision 3
of 2026-09-06 settled as all five modules. `05-03` built copy for the three
kinds that have containers. A contact has no one container, which is why
`pim_command.rs:49` to 54 gives the reason inline for leaving it out: a contact
is in as many groups as somebody puts it in, so there is no one home to move it
out of. That reason is correct and it is not a refusal, it is an unanswered
question. Nothing in the program asks which of a contact's groups it is coming
out of, and this plan is that question and the write behind it.

Output: a contact that moves between groups in one action without ever being in
neither, a chooser that asks the only question a move needs, and a copy that
reaches the code that already does it.
</objective>
