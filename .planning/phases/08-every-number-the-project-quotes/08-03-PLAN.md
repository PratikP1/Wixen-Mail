<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the harness to the application | a started process that shows a dialog, exits, or never writes the line produces a run that looks like a number |
| the profile to real data | a writer pointed at the real data folder would put a thousand synthetic messages into somebody's mail |
| a definition to a number | the same word, cold or idle, taken two ways gives two numbers that read as one |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-11 | Tampering | the profile writer reaching the real data folder | critical | mitigate | the writer takes a path and the ignored tests build it in a `tempfile` directory; `tests/house_style.rs::test_no_test_builds_its_own_temp_folder` holds the tree to `tempfile`; the started process gets `WIXEN_MAIL_DATA` and `--read-only`. |
| T-08-12 | Repudiation | a number read off a run that never reached the usable line | high | mitigate | the harness polls for the line and reports a run without it as producing nothing; task 3's action forbids reading a figure off such a run. |
| T-08-13 | Information disclosure | the application's own process reported as the whole cost while WebView2 runs beside it | high | mitigate | the harness walks the process tree and reports both and the sum. |
| T-08-14 | Spoofing | the usable line emitted on a sort or a folder change and read as startup | medium | mitigate | `say_usable_once` answers once per process and a guard record breaks the once. |
| T-08-15 | Denial of service | the startup connection to the refusable account timing out and stretching the cold-start figure | medium | mitigate | the account's server is `127.0.0.1` on a closed port so the refusal is immediate; the summary records what the application did with it. |
| T-08-SC | Tampering | npm, pip or cargo installs | high | mitigate | no package is added; memory is read through the OS; `Cargo.toml` is touched by a version bump only. |
