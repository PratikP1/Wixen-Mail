## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a figure to the page | a number arrives on the page from a command somebody ran, or from a document somebody copied; only the first is a measurement |
| the page to every other page | a figure stated elsewhere is a second copy that can drift from the first |
| a check to the page it reads | a reading that passes over an empty or missing table reads as coverage |
