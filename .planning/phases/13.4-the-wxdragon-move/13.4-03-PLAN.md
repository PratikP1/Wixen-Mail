<objective>
Give the text reader's converter the markup with what the sender hid taken out, the markup the
formatted view already gets, and say the formatted view's sentence about blocks left out above the
words.

Purpose: ledger 938, opened by 13.3-19. The formatted view and `long_text`'s reader drop what a
sender hid since #90 and, since 13.3-19, at any depth. The text reader never has: it hands the
raw markup to the vendored converter, so a newsletter's hidden preview line is read twice, its
two hundred padding characters are read as symbols, and a block a sender marked `aria-hidden`
for screen readers is read to the screen reader user anyway. The text reader is the window most
NVDA users of this program read mail in, so the fix is least done where it matters most. Pratik
said yes to the recommendation on 2026-10-23 (D-01).

Output: the change to `body_text`, the text reader's cases taken red first, the module doc and the
target's header, the guard records, the changelog with a dated correction of 13.3-19's known
limitation, ledger 938 closed and an ear row opened, LIST-25's dated line, the four marks, and
the pull request.
