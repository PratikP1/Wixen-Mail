<objective>
Give the message window's automatic save a timer of its own, so its ticks never reach the
handler that runs the window's other waiting work, and so the save keeps happening on its own
after the move to wxDragon 0.9.23.

Purpose: today the automatic save's timer has no handler. Its ticks reach the one handler bound
on the window because at 0.9.17 a timer event reaches every handler on its owner, and that
handler saves when nothing else is waiting, or takes the waiting work when something is, so an
automatic save can start a look-up or a spelling check early. At 0.9.23 a timer reaches only the
handler bound to its own id (upstream #193), so those ticks would reach nothing, and a draft would
be kept on its own only when the other timer happened to fire after the interval had passed.
Somebody writing a long message with a screen reader would lose the safety net and not be told.

Output: the function, the composer wired to it, a live test and readings that were red first,
three guard records, the changelog, dated lines on three ledger rows, and the completion marks.
</objective>
