<objective>
Make every test that opens a live window end its event loop without sending the application
object to another thread, so the test files build under wxDragon 0.9.23 without being touched
again by the move itself.

Purpose: Pratik decided on 2026-10-20, "We need to update wxDragon to the latest version and all
that implies." The trial build of 0.9.23 made for the research refused 72 sites in 69 test files
with one error: the application object is not `Send`, and `call_after` requires a `Send`
closure. The fix works at 0.9.17 as well, so it lands first, on its own, where the suite proves
it changes nothing. The move in 13.4-09 then has one source file to mend rather than seventy.

Output: the reading, committed red and then green; the 69 files changed in two committed halves;
one guard record; the completion marks; a merge with no push, since nothing spoken or shown
changes.
</objective>
