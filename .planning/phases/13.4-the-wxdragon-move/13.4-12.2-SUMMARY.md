# Phase 13.4 Plan 12.2: A Letter for Each Format Menu Item Summary

**Every item on the composer's Format menu now has a letter no other item holds. Numbered List
is `M`, Undo `O` and Insert Link `K`, so `U`, `N` and `L` each run one item the moment they are
pressed instead of moving between two. Ledger 972 is closed.**

## What changed

The popup is described by `format_menu()` in `src/presentation/wx_compose.rs`: a
`Vec<FormatMenuLine>`, each `Command` a `FormatMenuEntry { id, label, help }`, in the order the
menu is read: the thirteen of `Format::ALL` from `ID_FORMAT_FIRST`, a separator, Insert Link,
Insert Table, Insert Picture. `show_format_menu` only walks that list into a `Menu` and pops it
up, with no string literal of its own. The red commit made this move with the labels, help text,
ids and order unchanged; the green changed three labels and nothing else in code:

| Item | Was | Now | Written in |
|---|---|---|---|
| Numbered List | `N&umbered List` (U, Underline's) | `Nu&mbered List` (M) | `editor_document.rs`, `Format::label` |
| Undo | `U&ndo` (N, Normal Text's) | `Und&o` (O) | `editor_document.rs`, `Format::label` |
| Insert Link | `Insert &Link...` (L, Bulleted List's) | `Insert Lin&k...` (K) | `wx_compose.rs`, `format_menu()` |

Each moved label carries a one-line comment saying which letter it gave up and why. The sixteen
letters are now B, I, U, 1, 2, 3, N, L, M, Q, F, O, R, K, T, P.

`tests/wired.rs` reads `names_after(&text, "id: ")` as raised for `wx_compose.rs` in both command
checks, the way the first already read the tray's `TrayCommands` fields, so the three
`id == ID_INSERT_*` arms stay raised and `ID_FORMAT_FIRST` keeps its `KNOWN_DEAF` entry, which is
untouched (`git diff f51c63c2 -- tests/wired.rs` adds two blocks after the marker loops and
touches no line of `KNOWN_DEAF`).

`docs/KEYBOARD_SHORTCUTS.md` has one paragraph after the Formatting table's two limitations,
opening "On the Format menu (`Alt+O`, or the Format button) every item has a letter of its own:",
naming all sixteen and the three that were shared. `docs/changelog.md` has the first entry under
`[Unreleased]`, `### Fixed`.
