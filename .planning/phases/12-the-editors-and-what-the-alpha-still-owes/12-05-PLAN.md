## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the log to the report | lines written for a machine leave the machine as an attachment |
| the dialog to the outbox | a report is a message and takes the gate every message takes |
| the dialog to the browser | two fixed GitHub addresses leave through the same opener a link uses |
| the machine to the report | a Windows build, a language and a screen reader's name are read from the system |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
