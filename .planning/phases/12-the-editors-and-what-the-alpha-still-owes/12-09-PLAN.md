<objective>
Signatures assignable per account, with one default for the rest.

Purpose: #43, the tester on 2026-09-15: "Allow signatures to be assigned
by email account. Default should apply if no signature is assigned to a
particular account." The tree has the other shape: signatures live only
under the account active when they were written, the manager shows one
account's set without saying so, a default is per account, and an account
with none gets none.

Pratik answered on 2026-09-23 where the choice is made: in both places,
one setting reachable from both. The account's own dialog keeps it, and
the Signature Manager can assign a signature to accounts and set or clear
the default, writing the same stored assignment, with a reading that what
either sets is what the other shows the next time it opens.

Output: the resolution as a pure rule, the assignment table and the pass,
the manager over one set, the choice on the account dialog and in the
manager's signature editor, compose
following the From account, the reading, the guide, the changelog, the
ledger. Closes #43 on the tree side.
</objective>
