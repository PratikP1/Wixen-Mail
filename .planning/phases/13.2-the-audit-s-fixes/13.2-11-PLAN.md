<objective>
Replay a change kept from offline only into the folder numbering it was
kept under, and stop an older waiting flag change overwriting a newer one
that already reached the server.

Purpose: finding #5 and finding #2, neither reported. A waiting move or
delete is sent by number with no check that the server has not renumbered
the folder since; after a renumbering the same number can name another
message, and a waiting permanent delete expunges it, with nothing to undo.
And a read or star change that reaches the server leaves any older waiting
change to the same message in place, so the next check sends the old value
and the person's last change is reversed at the server and here; the
replay's own let-go deletes by message and flag, so a newer change kept
during the replay's round trip is lost.

Output: the numbering recorded and asked, one decision for all three
replays, the two narrowed lets-go, the readings, the changelog, the ledger,
the four marks, and the pull request.
</objective>
