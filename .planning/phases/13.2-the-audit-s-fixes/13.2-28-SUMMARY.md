# Phase 13.2 Plan 28: The pretend accessibility tree goes Summary

Start-up now says "Wixen Mail is ready" alone. It used to add "Focus moved to Folders", a
sentence built from a name stored in `KeyboardHandler`, `FocusManager` and `AutomationStore`,
a model of the window that reached neither UI Automation nor MSAA. That model is deleted. And
a shipped build no longer keeps a copy of every line it handed the screen reader, message text
read aloud included; the list exists in a test build alone.
