# Phase 13.2 Plan 26.1: What a documents commit runs Summary

A commit that changes only documents now runs the formatting check and the targets that read
documents, and no longer touches `src/lib.rs` or runs clippy. A run for changed code still
does both, and the refusal of a commit that leaves source on disk still comes before any of it.

## Pratik's answer

Task 1 was a checkpoint. Pratik answered on 2026-10-14, in his words, "yes to both", and the
brief for this run said the checkpoint was answered yes. Audit finding #45 is settled by that.

## What changed

**`scripts/check.sh`.** `touch src/lib.rs` and the clippy stage each sit inside
`if [ "$mode" != "docs_only" ]`. rustfmt stays where it was, between them, and 13.2-25's
refusal stays above both. The `docs_only` closing message says clippy did not run and that
CI's Clippy job lints every push. The header comment about the touch says it applies wherever
clippy runs.

**`scripts/which-checks.sh`.** The `docs_only` row of the answers table says what now runs.

**`CLAUDE.md`.** The two sentences saying a documents commit runs "formatting, clippy" carry
"(until 2026-10-18)", and the merge sentence says clippy does not run for a diff of documents
alone. A new paragraph after them gives the rule, the date, his words, this plan and the
reason.

**`scripts/check.test.sh`.** Four new cases run `check.sh --message-file=F <mode>` in a
repository of their own, with a stand-in `cargo` first on the path that writes down every call
and does nothing:

| Case | Red at 2b1e985e | Green at fe517abb |
|---|---|---|
| a documents-only run calls no clippy | red: the stand-in saw `clippy --all-targets ...` | ok |
| a documents-only run touches no source file | red: `src/lib.rs` newer than the reference | ok |
| a run for changed code still touches and calls clippy | ok (companion) | ok |
| a documents-only commit leaving source on disk is refused before cargo | ok (companion) | ok |

The first case also requires the stand-in to have seen `fmt --all -- --check`, so it cannot
pass on a run that never reached a stage. The two timing cases that relied on `docs_only`
stopping at the touch now ask `affected`, with a comment saying why.
