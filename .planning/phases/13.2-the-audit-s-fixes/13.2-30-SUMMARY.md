# Phase 13.2 Plan 30: One translation system, and only crates the program calls Summary

The `I18n` registry in `service::spellcheck` is deleted, and the Fluent catalogue in
`common::catalogue` is the one translation system. The two words said before a picture's
description, "Image" and "Figure", are English literals, held by a case that was taken red by
swapping them. `icalendar` and `quick-xml` left the manifest, `rand` moved to
`[dev-dependencies]`, and a census in `service::outward` fails on the next crate a release
build carries and does not call. Nothing a person does, sees or hears changed.

## What changed

`test_a_picture_and_a_figure_are_each_labelled_with_their_own_word`, asserts "[Image: Revenue

`let label = if is_figure { "Figure" } else { "Image" };`. The five vendor headers, the
paperback module doc, the image case's comment and the spellcheck module doc say what the
code does.
