# Phase 13.2 Plan 31.5: The refusal beside the address box Summary

When Add or Edit Account refuses an address another account uses, the sentence now also shows
on a line under the address box, inside the window that refused it, and goes when the address
changes; every window's status line shows an ampersand as written and claims no letter from it.

## What changed

- `status_line::as_a_label` doubles every `&`. `said_and_shown` and `shown_and_signalled` put
  the sentence on the line through it and say or signal it as written.
- The Add and Edit Account window has `address_refused`, an empty line in the second column
  under the address box, part of `IdentityFields`, shown with the first page only while it
  holds a sentence.
- `show_why_the_address_was_refused(w, Option<&AddressTaken>)` sets the line through
  `as_a_label`, wraps it at the address box's width, names it with the sentence as said, shows
  it only while the address box shows, and lays the window out. It returns at once when asked
  to clear a line that holds nothing.
- `show_edit` calls it with the refusal after `said_and_shown` and before
  `back_to_the_address`. The address box's handler calls it with `None` before it reads the
  address. Nothing new is said.
