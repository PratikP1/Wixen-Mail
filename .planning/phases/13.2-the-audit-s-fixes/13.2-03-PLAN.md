<objective>
Make the conversation window act on the message under its cursor: the menu
key, Delete, Shift+Delete and M, reusing the command code the list uses,
and coming back up to date.

Purpose: Pratik, 2026-10-14: "When the thread is opened, user is unable to
use context menu or other commands that can act on a message within the
thread. Actions can only be taken on an entire conversation upon returning
to the mailbox." The window is a modal picker with no key, menu-key or
menu handler; the main window cannot answer while it is open; and every
command reads its target from the main list. Since `478f5885` made
conversations the default, it is the only place a conversation's messages
are listed one by one. The other message keys (Ctrl+R and the rest) and
marking a message read from the window are 13.2-03.1, the next plan,
split off because one executor could not carry both; until it lands, Reply
and the rest are reached here through the menu key.

Output: the target, the window's answer and the loop, the readings, the
keyboard page, the changelog, the ledger, the four marks, and the pull
request.
</objective>
