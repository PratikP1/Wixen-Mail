Delete the pretend accessibility tree and make the bridge's copy of
every spoken line a test-only list, so start-up says only what is true
and a long session stops holding everything it read aloud.

carries R20 of the audit, which is findings #37 (ui) and #47 (lean),

`AutomationStore` are a model of the window that reaches neither UI

stored. Beside it, `ScreenReaderBridge::event_log` keeps a copy of every
released line, whole message bodies read with Space included, for the
life of the process, and only tests read it.
