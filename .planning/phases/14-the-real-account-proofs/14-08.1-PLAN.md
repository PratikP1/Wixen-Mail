<objective>
Close ledger 902. When a draft is saved again, Wixen Mail files the newer copy in the
server's Drafts folder and removes the older copies. It finds those copies with the server's
search for the draft's Message-ID, which also answers any message whose Message-ID merely
contains the draft's, and it removes every number the search answers. This plan makes the
save read each number first and remove only the ones that really carry the draft's
identifier, the way Send's removal has done since 13.2-31.4 (ledger 854).

Purpose: a stranger's message whose identifier holds the draft's would be taken out of Drafts
at the next automatic save, which runs once a minute while somebody writes. A draft's
identifier is this program's own, `<draft-ID@wixen-mail.invalid>`, so this is unlikely rather
than impossible (ledger 902). Pratik approved the fix on 2026-10-20, to land before 14-08.2
makes the build the sittings run on, so that build holds it.

Output: the shared reading and its cases, the loopback cases moved to a server that holds the
draft's copy, the guard records, the changelog entry, ledger 902 closed with two rows opened,
FOUND-04's dated line, and the four marks.
</objective>
