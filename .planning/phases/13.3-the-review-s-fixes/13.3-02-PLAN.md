<objective>
Make a delete or a move made on this computer leave the list and the conversation rows
at once, and make a reopened conversation stop listing a message deleted inside it.

Purpose: two must items from the review of 13.2. Item 1: inside an opened conversation,
Delete on a POP message moves it to the local Trash but its row leaves the list only at
the next timer tick, and the conversation reopens before that tick, still listing the
message with the cursor on it; a second Delete then finds it in the Trash and erases the
only copy with no question. Item 15: 13.2-02's catch-up names the touched conversations
by reading the store after the change, and three changes erase what it reads, so the row
stays until the folder is read again. Both are the "Delete shows only after the next
sync" report 13.2 set out to fix, on the paths it did not test.

Output: the delete and its catch-up, the readings and the cases on the built list, the
changelog, a ledger row for the ear, the four marks, and the pull request.
</objective>
