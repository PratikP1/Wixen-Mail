misses the cache stops spending about ten minutes packing a save that GitHub then refuses.

steps for a median 579 s, and every one of those saves since 2026-09-14 was refused, 81 of 81,
because Clippy restores and saves the same keys and finishes first. Every first pull request run
since 2026-10-14 has missed, so a pushed plan has waited a median 44 minutes for the Test Suite
against about 20 to 26 on a hit (premise 1). Pratik answered "Let's do all of them" on 2026-10-22
to the speed-ups the CI investigation listed, this one among them. The investigation and its
adversarial check are the sources of every figure below.

Output: the three cache steps in `ci.yml` on the restore action, the reading in
`tests/house_style.rs` that was red first, two guard records, the records naming
`tests/house_style.rs` re-measured, one ledger row for the runner's word, FOUND-23's dated line
