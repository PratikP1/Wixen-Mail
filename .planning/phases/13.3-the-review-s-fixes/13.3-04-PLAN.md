<objective>
Send a read, star or label change to the server of the account the message is in, for
every message a command can reach, and stop a change let go during a check's replay from
being sent after a newer one.

Purpose: item 3 is a must. In All Inboxes under conversation view, M, Star and Label reach
the whole conversation, including the person's reply in Sent, which the list never loaded;
`owner_of` finds no loaded row for it and falls back to the open account, so the change is
sent to another account's server with this account's folder path and number, where it
marks an unrelated message, and the message's own server is never told. 13.2-03.1 added a
second way in. Item 18 is the race 13.2-11 closed in one order, in the other: a check's
replay reads the waiting list, a fresh M reaches the server and lets the older change go,
and the replay then sends the older change, so the person's newest mark is undone at the
server and, at the next check, here.

Output: the rule and its cases, every caller handing its store, the account's flag turn,
the waiting store's answer, the readings, the changelog, the ledger, the four marks, and
the pull request.
</objective>
