# Phase 13.3 Plan 16: Each folder opened once per run of changes, and once per destination

A run of replayed changes in one folder now opens that folder once: the IMAP session answers
an open folder's numbering from the SELECT that opened it, so a run of deletes outright, the
Trash emptying at a check and at close among them, no longer opens the Trash again for every
message (review item 34). A SELECT the server refuses now leaves no folder taken to be open, so
a flag change is no longer sent to a folder the server has closed. A check whose rules file
messages into several folders moves and settles one destination at a time, so the source
opens once per destination and each destination once, rather than four commands per filed
message (review item 21). Nothing is spoken or shown differently, so the branch was not pushed.

## What was done

- **Task 1, red then green (tracer).** `ImapSession` gains `numbering_of_the_open_folder`, set
  with `selected` when a SELECT succeeds and cleared with it before every SELECT is sent.
  `ImapSession::the_numbering_of` answers it while the folder asked about is the one open and
  otherwise opens the folder; its doc cites RFC 3501 2.3.1.1 and says why `select_folder` still
  asks every time. `MailController::the_numbering_of` reaches it through
  `once_more_if_the_connection_went!`, and both `numbering_of` impls for `MailController`, in
  `moves_waiting.rs` and `mail_across_accounts.rs`, call it. Red at `db97065f`, green at
  `4b131fba`.
- **Task 2, red then green.** `Scripted` writes each move and each `where_it_is` question into
  `happened` with its folder. `carry_out_the_moves` groups the moves through `by_destination`,
  in the order each folder is first named, and for each group moves every message with the
  source open, moves each row here, then settles every moved row with the destination open.
  Red at `e3525234`, green at `3f043c08`.
- **Task 3.** Ledger 933 in both halves with the header counts; MAIL-02 and LIST-21 a dated
  line and a row clause each, no `[D]` clause; the four marks; this summary.
