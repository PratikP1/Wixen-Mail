<objective>
Make a Google calendar, contacts or tasks sync that Google refuses for a permission the sign-in
was not given say so, name which one, and name the button that fixes it, instead of "1 error".

Purpose: ledger 932, opened by 13.3-15 on 2026-10-21, and Pratik's "yes to 3" of 2026-10-22

Contacts or Tasks on Google's consent screen and keep the sign-in; the sync is then refused with
403, the refusal is pushed as an error string, and all a screen reader user hears is a count,
naming no cause and no way out.

turn it into a reason with a sentence, the Help page's bullet, the changelog, the ledger, REAL-01's
dated line and the four marks. What is spoken changes, so the branch is pushed and a pull request
opened under Pratik's standing OK of 2026-09-23.
