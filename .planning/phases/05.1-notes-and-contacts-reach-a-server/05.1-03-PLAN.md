<objective>
Build the first notes backend behind the seam, and the storage it needs, with
nothing added that nothing reads.

Purpose: PIM-07's remaining three `[D]` lines. `05.1-02` built the seam, wrote the
contract and shipped no backend. This plan writes the first one, the columns it
needs, and the record of deletions without which a deleted note comes back on
the next read.

This is CalDAV VJOURNAL, decided on 2026-09-06, and it is the first of three
rather than the only one. It is first because the transport, ETag handling,
conflict raising and the document reader and writer all exist, and because it is
the only candidate whose round trip can be byte-identical, which PIM-04
requires. Write it against the seam, not beside it: `05.1-04` puts a second
implementation behind the same seam within the phase, and phase 5.2 puts a third
behind it that agrees with almost nothing this one does.

Output: notes that reach a backend, a deletion that stays deleted, a conflict
that is held rather than resolved, and an honest ledger of everything that has
never met a server.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a backend's document over the network -> the document reader | attacker-controlled or malformed text handed to a parser that has only ever seen text this repository wrote |
| a backend's own list -> what is written into the local database | a remote party decides which notes exist, and a wrong answer writes over somebody's own work |
| a note body -> a document sent outward | private text leaves the machine, and what leaves must be what was asked for and nothing else |
| a backend sign-in -> the credential store | a password for somebody's server |
