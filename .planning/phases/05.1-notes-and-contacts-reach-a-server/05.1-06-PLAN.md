Let somebody add a CardDAV address book by its address, sync contacts both ways
with it through the merge that exists, and make sure the password does not
outlive the program.

`05.1-05` is a module nothing reaches. `CLAUDE.md`'s first guardrail is that no
feature is done until a non-test path reaches it, and this is that path.

Output: a screen, a table to keep an address book in, a sync that feeds the
existing merge rather than a second one, a credential owner registered where
uninstalling reads it, and an honest ledger of everything that has never met a
server.
