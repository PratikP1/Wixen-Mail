# Phase 13 Plan 44.5: One check of who runs an account's mail Summary

A Google Workspace account whose incoming server is `imap.gmail.com`, or a Microsoft 365
account on `outlook.office365.com`, is now Gmail or Microsoft everywhere Wixen Mail asks:
Report as Junk, the folder chooser, both halves of the browser sign-in, the account editor's
app password advice and Get an app password button, and Send Feedback's account kinds. One
function decides, `application::who_runs_the_mail::WhoRunsTheMail`, and a census refuses a
second place.

## What was built

- **The check** (`src/application/who_runs_the_mail.rs`). `WhoRunsTheMail { Gmail,
  Microsoft, SomebodyElse }`, `WhatIsKnown`, `of(&Account)` (the POP server for POP, the IMAP
  server otherwise, the address, the saved name) and `from_what_is_known`, one chain of three
  private readings: the server by domain at a label, the address through
  `OAuthService::detect_provider`, the saved name trimmed and ignoring case.
  `oauth_provider` gives the keychain name, `app_password_url` Google's page alone.
- **Report as Junk.** `AccountKind::of` keeps POP first, then asks the check.
- **Sign-in.** `mail_auth::provider_of` asks the check; `run_oauth_flow` asks `provider_of`,
  so a token is filed and read back under one name. `NO_BROWSER_SIGN_IN_HERE` is what the
  Account Manager says after "Signing in failed: ", `no_browser_sign_in_for` what a mail check
  says, both naming the IMAP or POP server. The NVDA case waits for the new words.
- **The folder chooser.** `choose_folders` sets `is_gmail` from the check;
  `is_a_gmail_account` and its three cases are gone.
- **The account editor.** `password_box_description` and `where_to_get_an_app_password` ask
  the check with the address and the incoming server typed. `show_the_password_advice` is the
  one writer of the hint and the password box's description, called when an account opens
  and from the address box, new `on_text_changed` handlers on the IMAP and POP server boxes,
  the protocol choice and the browser sign-in box. For 13-44.6: the IMAP server box's handler
  is `imap_f.on_text_changed(...)` just after the address box's handler; call
  `show_who_empties_the_trash` from there rather than binding a second one.
  `MICROSOFT_ASKS_FOR_THE_BROWSER` is D11's sentence. `data::account::offers_app_passwords`
  and `app_password_url` are gone with their four tests; `oauth_is_default` stays.
- **Send Feedback.** `this_machine::providers` names "Gmail" or "Microsoft" by the check, and
  only for somebody else the saved name or the protocol.
- **The census** (`tests/one_check_says_who_runs_the_mail.rs`). Eleven callers by signature
  or file, six shapes of deciding for oneself allowed only where `THE_SHAPES` says, and a
  companion planting six faults.

Reachability: Report as Junk reaches `AccountKind::of` from `report_the_chosen_as_junk`; the
mail check's `for_account` and the Account Manager's `run_oauth_flow` reach `provider_of`;
`choose_folders` is Action's Folders to Keep Up to Date; the editor's handlers are bound in
`show_edit`; `open_send_feedback` calls `providers`. The pull request's NVDA job is where the
sign-in failure sentence is heard.
