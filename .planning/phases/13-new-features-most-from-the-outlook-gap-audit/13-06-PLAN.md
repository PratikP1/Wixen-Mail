<objective>
The same several-step history in every dialog with a text field, and a
reading that keeps it there.

Purpose: #47 asks for Undo and Redo "in every dialog with a text field
... with a multi-step history where the native control gives one step."
13-05 built the history and bound it in the main window. Dialogs have
no menu bar, so the box's own key-down (bound by `keep_a_history`)
takes Ctrl+Z and Ctrl+Y there. With this plan GAP-02's first half,
"Edit, Undo and Redo for the focused control on every surface", holds
for every text box this program builds.

Output: the history reaching every editable box, the reading, the pages
naming what keeps Windows' one step, the changelog, the ledger.
</objective>
