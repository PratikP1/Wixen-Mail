is `__properties_version1.0`, a header then 16-byte entries (Property
Stream, 20c1125f); the top level's header is 32 bytes: Reserved 8,
Next Recipient ID 4, Next Attachment ID 4, Recipient Count 4,
Attachment Count 4, Reserved 8 (Top Level, ed03f930). A
