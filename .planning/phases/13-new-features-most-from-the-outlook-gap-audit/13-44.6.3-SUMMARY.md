## Deviations from Plan

1. **The lock record reddens three cases, not two.** The plan named the failed and bound cases; the never-reported case ends with the lock clause as well, and the record names what really went red.
2. **Both key censuses went red in each red commit, not one.** 13-44.6.2's premise paragraph says removing the allowance brings the five under both censuses, so task 1's red named the desktop census and the modifier census, and task 2's red named both and the browser rule. Each was accepted by `red-commit.sh`.
3. **The browser list's check against the program is part of the rule case, not a third case.** D8's sibling case reads `pub fn build_compose_dialog(` in `src/presentation/wx_compose.rs` and `pub fn show_conversation_as_page(` in `src/presentation/wx_app.rs` at the top of `test_a_key_sender_with_a_browser_runs_in_a_child_and_takes_the_one_turn`, so the dialog target gains two tests as the plan counts.
4. **Every key the five send now goes through `only_these_modifiers_down`**, as 13-44.6.2's premise paragraph asks: none down for the marker's characters, the From list and the spin-control list; Alt alone for Alt+C and Alt+R, cleared once the loop has read the key. The posted keys leave the state as set rather than putting it back, since a posted key is read when the window takes it.
5. **The turn's wait is six minutes in the four browser targets**, the child's five-minute bound and a minute more, since a run holding the turn is stopped at that bound. The paste target keeps its two minutes, so a paste run that meets a browser target's child on the turn can now wait out a run of up to a minute; nothing was seen to do so.
6. **Ledger 778 is closed here**, since this plan did what it handed over.
7. **A banned tool ran once.** Reading the guard records file's header, one read-only command carried `sed -n` piped to nothing; nothing tracked was touched, and every read after it went through the Read tool. It is logged to the observation log.
8. **No commit on `main` after the merge**, as in 13-44.6.1 and 13-44.6.2: the brief allows one documents commit before the merge, so the merge's mode line is in the run's report.
