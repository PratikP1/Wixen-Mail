<objective>
The outbox and the drafts remember which address a message was written
from, and sending uses it.

Purpose: the data half of RESEARCH-3's C11, which it sized large and
split in two: `SendEmailRequest::from_queued` takes the account's own
address (`mail_controller.rs:170`), and the outbox row and the draft
hold no From, so an address chosen in compose would be lost between the
window and the server. This plan carries it; 13-35 lets a person choose
it.

Output: two additive columns on each table, the fields, the reads and
writes, `from_queued` and the draft filing through one rule, the literal
sites updated, the round-trip target, the changelog and the ledger.
</objective>
