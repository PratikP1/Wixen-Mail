# Phase 11 Plan 11.0: What the sender hid is not read, a layout table is not a table, the page's own markup said once Summary

**Text a sender hid is dropped before the sanitiser sees a message, by the sender's own hiding
and never by what the block says: `display:none`, `visibility:hidden`, `font-size:0`,
`max-height:0` with `overflow:hidden`, `mso-hide:all` and `aria-hidden="true"`, with
`opacity:0` alone not a rule; the invisible filler a preheader is padded with is stripped
wherever it stands and a text node of filler alone goes whole; a hidden block that held words
beyond a short preview line is counted and said once at the top, in the same paragraph as the
pictures' sentence. A layout table keeps `role="presentation"` on its four tags and no other
role survives, a sender's `aria-label` is kept only where it is a link's or a data table's
name, and the page's own heading numbers a message only in a conversation. The reader that
makes a row's snippet and reads a message's structure runs the same drop, reads a layout
table as its blocks and walks a `div` of blocks as blocks, so the newsletter's four joins of
ledger 555 are apart. The tester's Substack message is in the tree as a public fixture with
its thirty tracking addresses replaced by hand, and every reading runs over it. The plain
part is never parsed and a message on its way out keeps what its writer hid. Nobody has heard
the newsletter read once; #90 is closed from the merge with the ear list.**
