**1. The header before each cell is NVDA's, from one setting, and no

So NVDA speaks the header before every column but the first when its
Document Formatting setting "Row/column headers" is "Rows and columns" or
"Columns", which is the default, and the first column never gets one. The
tester's report is that reading. The comment in `message_rows.rs` said the
opposite, from nobody's ear; it is corrected in task 1 without changing
what the cells say, because a cell that stands on its own is right whether
or not a header precedes it.

**2. The three routes, and which is taken.**

- The application speaking the row itself on selection would double every
  row, since NVDA's own reading cannot be turned off from here.
- An NVDA app module is an add-on the person installs into NVDA, with its
  own packaging, versioning and a second repository's worth of testing;
  nothing under `nvda-tests/` is one (that directory drives NVDA, it does
  not extend it), and it would serve NVDA alone. Later work if the profile
  below is too much to ask; recorded in the ledger.
- An NVDA configuration profile triggered by Wixen Mail, with Document
  Formatting's "Row/column headers" set to "Rows" or "Off" inside it, so
  every other program keeps its headers and this one does not. NVDA's own
  feature since 2013, no code, and it leaves Narrator and JAWS as they are,
  which each have a verbosity setting of their own for the same thing.

The third is taken. What a reading can prove: the command exists on the
Action menu with its chord; what it composes for a message row and a
conversation row from the visible layout; that it announces once as
content; that the page carries the steps. What only the ear settles: that
traversal is quiet under the profile, that the on-request reading is
heard whole, and what Narrator and JAWS need.

reaches the window.**

The item is on the Action menu, "Read the Row's &Columns\tCtrl+Shift+;"
if C is free on the day, else a letter the builder shows free, and
`test_no_two_items_on_one_menu_claim_the_same_letter` holds it. wx
parses a one-character key after the last plus, and on a US layout `;`
is `VK_OEM_1`; on a layout where `;` is elsewhere the chord follows the
key, which the page says. The arm works when the message list holds
focus and a row is selected, and says "Nothing is selected in the
message list" otherwise, because an accelerator fires wherever focus is.

**4. What a row's reading is made of.**


The reading is the visible columns in their order, each as "heading, text"
except the six self-describing columns, whose text is said alone, and
