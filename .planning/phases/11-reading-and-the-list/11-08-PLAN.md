<objective>
Make a conversation row stand for the originator when every message is
unread and for the first unread message otherwise, report that message's
sender first, preview and open on it, and fetch the text of the whole
conversation when the row is selected.

Purpose: #31, the tester on 2026-09-16: "Focusing on a thread in the mail
list should use the originator of the thread ... as the first reported
correspondent and the associated message if all the messages in the
thread are unread. If not, then the first unread message should be
highlighted ... Currently, the last message is highlighted. If a thread is
highlighted, all messages should be cached." Today the row's snippet is
the newest message's, the senders come in stored order, and the preview
under conversation view shows a message that is not the row's at all.

Output: the row message chosen in SQL where the columns are, carried on
the row, read by the cell, the sort, the preview and the window; the
conversation's text as one chunk on selection; the readings; the pages.
Closes #31 on the tree side.
</objective>
