Taken 2026-09-16 against `main` at `524ff24f`. Command first, then what it

**1. The dialog builds seven pages before it shows, and three of the costs
the issue names are where it says, one line off.**

```
grep -n 'fn build_settings_dialog\|available_languages()\|installed_families()\|SoundScheme::discover\|notebook.add_page' src/presentation/wx_settings.rs
  -> 209 build_settings_dialog; 638 available_languages(); 762 installed_families(); 2714 SoundScheme::discover; add_page at 241, 252, 276, 282, 288, 293, 299 (seven pages, not five)
grep -n 'show_settings_dialog\|fn handle_settings' src/presentation/wx_app.rs   -> 16499 handle_settings; 16538 the call, after ConfigManager::new() at 16508 and a cache query for a calendar server at 16529
```

`show_settings_dialog` (`wx_settings.rs:154`) builds then `show_modal`s;
`build_settings_dialog` returns the widgets without showing, which is what the
two existing dialog-building targets use.

**2. The 08-03 instrument.** `src/common/started.rs` holds the process's
start instant and words one line a harness parses; the harness
`tests/the_numbers_the_targets_ask_for.rs` starts the release binary and reads
its log. A dialog open is not process start, so the shape here is: a log
line `settings built in N ms` written in `handle_settings` from an `Instant`
taken at the top of the `ID_SETTINGS` arm to just before `show_modal`, worded
by one function with a test; and a harness that builds the dialog in-process
and times the three candidates alone, because starting the binary and
pressing `Ctrl+,` from a test needs an input driver this tree does not have.

**3. What can be timed without a window.** `available_languages()`,
`fonts::installed_families()` and `SoundScheme::discover(&dir)` take no
window; the first two ask Windows. `build_settings_dialog` needs the one
window a test process may build. So the harness is one `#[test]`, ignored,
run with `--release --ignored --nocapture`, that times the three functions
five times each, then builds the dialog once and times that, and prints one
line per figure in a fixed shape the summary quotes.

**4. Nothing is remembered between opens, and remembering has a cost the
summary must state.** A font installed while the program runs would not
appear in the list until restart if `installed_families` is kept once per
process; a spell-checker language added the same way likewise. Both are
rare and both are said in the changelog under Known limitations if that is
the change the rows justify. Building a page when its tab is first shown
keeps the lists fresh and moves the cost to the first visit of that tab.
Filling a list after the dialog shows needs the control to say "loading" on
both channels until it is filled, per guardrail 5. The rows decide.

**5. Records and the gate.** `wx_settings.rs` 8 records, no unit tests;
`spellcheck/mod.rs` 30 records; `fonts.rs` 0 records, 5 tests; `started.rs`
3 records, 6 tests; `wx_app.rs` 50 records. The harness is a new target at
zero records; ignored tests are still tests, and it gets a record like
`the_numbers_the_targets_ask_for` has (`grep -n 'the_numbers_the_targets_ask_for' guards/guards.toml | head -2`).
`docs/development/measurements.md` is read by
`every_number_carries_its_command_and_its_date` on every commit and on a
documents-only one.
