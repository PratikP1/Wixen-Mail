(`what_the_file_holds`); Thunderbird stores each folder as an mbox file
with no extension beside a `<name>.sbd` directory of subfolders and a
`<name>.msf` index. So a Thunderbird profile's mail directory read here
gives every mbox file as a folder, every `.msf` refused as not mail, and
the nesting flattened. That is a limitation to say, not to fix here; the
Known limitations line says it and names Thunderbird.
