## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a stranger's data file to the parser | a `.pst` is a file somebody else wrote; a fault in the reader is reachable by whoever made the file, which `Cargo.toml`'s crate paragraph already names |
| imported mail to the sync | a row filed without the imported marker is deleted by the next sync as mail the server no longer has |
| Save As to the disk | a message's bytes and an attachment's bytes leave the cache as a file the person chose; the name suggested must not carry a path |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
