<objective>
Make every surface that shows a message try the PGP key, state the S/MIME
envelope and carry the signature bar, from one path, so the default way of
opening mail stops being the one that explains nothing.

Purpose: `read_messages_as` defaults to Formatted, and the Formatted reader and
the preview pane are the two surfaces that never offer a PGP message to the
imported key and never say what a signature was worth. A fresh install that
imported a key still sees "Wixen Mail cannot open it" over the armour. Two of
five surfaces work because two call sites were written; one function called
by five is how they stop coming apart.

Output: a composition module with tests, five surfaces asking it, the preview
with a bar, the guard widened, the changelog corrected. Closes #51 on the
tree; nothing here has met a real correspondent's key, which is the standing
condition.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a stranger's message to the reader | an armoured body, a signature and an envelope all come from outside; what is said about them is a security claim read aloud |
| the private key to a surface | the key is used only where the composition runs; a surface that bypasses it never decrypts, which is the defect, and a surface that decrypts without saying so would be worse |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-22 | Spoofing | a signed message previewing as unsigned, or an unsigned one as signed | high | mitigate | the composition's signature verdict is the one `checking_signatures` already computes, applied on every surface, with the preview's bar tested |
| T-09-23 | Information disclosure | a decrypted body reaching a surface that does not say it was decrypted | medium | mitigate | `the_body_to_show` and `with_pgp` are applied together by the one ordering function; a test holds the finding beside the body |
| T-09-24 | Tampering | the envelope sentence folded after the signature and never spoken | medium | mitigate | the ordering function fixes the order and a test holds the envelope inside the spoken cut |
| T-09-25 | Denial of service | a guard that names a surface by a `fn` line that no longer exists | low | mitigate | `body_of` panics on a missing opener, which is a failing test and not a silent pass |
| T-09-SC | Tampering | npm, pip or cargo installs | high | mitigate | no package is added |
</threat_model>
