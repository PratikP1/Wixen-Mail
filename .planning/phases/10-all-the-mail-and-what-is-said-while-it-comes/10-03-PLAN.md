<objective>
Make how much message text stays on this computer a setting, default all of
it, before the download of everything is wired, because the body cache
evicts above half a gigabyte at the end of every folder sync and would undo
the download on any mailbox whose text is larger than that.

Purpose: #23 in the tester's words: "Unless explicitly forbidden, message text
should be downloaded along with mail." The forbidding already exists as the
Message Text box on the Permissions tab. What does not exist is any way for
the text, once downloaded, to stay: `BODY_CACHE_BUDGET_BYTES` is a constant
whose own doc comment says a setting would plug into
`keeping_bodies_under` if anyone asked. #23 asks.

Output: one setting end to end, its default All, the eviction reading it, the
cache handed it where the workers open one, and the changelog entry.
</objective>
