`versions_named_in` and checks what comes back. That proves the extractor. It
proves nothing about the files being opened, being non-empty, or being the files

is flat: `src/presentation/wx_app.rs:19806`, "Nothing in this crate builds a
live wxWidgets window inside `cargo test`", which is false and was false when it
was written, because `tests/theme_reach.rs` has built one since before it. A
second, at `:25434`, says "no test in this crate can reach it"; the narrow claim
there is true, because the thing is a closure inside the window builder, but the

`one_question_at_a_time.rs:36` and `view_state.rs:3`, say wxWidgets supports one
application per process and that this puts a hard ceiling on how much can be
proved by building one. That is true and is not the correction: it is the
premise, and what is missing from it is the number. The correction is that the
ceiling is one live window per process, measured by 02-04 in both directions,
and a second in the same process prints an initialisation complaint and hangs.

comment at `:11-20`, including the hang. So this plan is copying a sentence that
exists in the tree into the five places that contradict it, not deciding
anything new.
